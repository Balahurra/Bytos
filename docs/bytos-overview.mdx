## What is Bytos?

Bytos is an open-source, **bring-your-own-key (BYOK)** autonomous AI coding agent
for **Visual Studio Code**. It reads your workspace, plans before it edits,
implements changes through reviewable diffs, runs commands in the editor
terminal, uses the browser and MCP tools with your approval, and records
checkpoints you can restore.

There is no Bytos account, subscription, or hosted backend in this build. You
connect the model provider you already pay for. API keys are stored in VS Code
SecretStorage and are never sent to the webview.

## Auto Phase Plan

**Auto Phase Plan** is Bytos's sequential multi-phase orchestration mode:

- up to **10 ordered phases** run automatically from phase 1 to the last phase
  you configured;
- each phase is its own **Act-mode task**, with its own prompt, provider, model,
  API key, attachments, and MCP server allowlist;
- a phase's settings do not leak into the next phase unless you explicitly copy
  them;
- when a phase fails or reports `BLOCKED` / `FAILED`, you can stop the plan,
  continue automatically, or be asked each time;
- every run writes a detailed Markdown report to
  `.bytos/auto-phase-reports/<run-id>/report.md`, with an overall summary of the
  phases;
- an optional AI-generated final summary is available and off by default;
- starting a plan shows a confirmation warning, and the run can be stopped at
  any time.

Auto Phase is **sequential**, not a parallel multi-agent fan-out.

## What ships in the VS Code extension

- chat-first agent with Plan / Act modes and approval-first tools;
- multi-provider BYOK configuration, including local models;
- file editing with diffs, terminal execution, browser automation, and MCP tools;
- hooks, skills, worktrees, checkpoints, and task history;
- sequential Auto Phase Plan with per-phase settings and Markdown reports;
- local voice dictation on **Windows x64** (microphone discovery, per-device
  selection, bundled whisper.cpp engine; speech models download on demand);
- opt-in telemetry, disabled by default.

## Install

1. Install [Bytos from the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Bytos.bytos).
2. Open the Bytos view in the activity bar.
3. Open **Settings → API Configuration**, choose a provider, paste your API key,
   and select a model.
4. Describe a task in the chat box.

See [Installing Bytos](/getting-started/installing-bytos) and
[Quick start](/getting-started/quick-start) for the full first-run path.

## What is not part of this release

The following surfaces exist in the repository or in historical documentation
but are **not distributed in the current VS Code extension release**:

- Desktop app
- CLI, TUI, ACP, and cloud agents
- JetBrains plugin
- SDK and plugin marketplace
- Kanban
- Bytos Provider / BytosPass hosted billing
- Enterprise SSO, remote configuration, and monitoring
- Public Bytos API

See [Status and roadmap](/status-and-roadmap) for the shipped-versus-planned
matrix.
