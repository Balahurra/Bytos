Bytos tools are executable actions the model can request while working. The model
proposes a tool call; Bytos checks permissions and either asks you to approve it or
runs it under an auto-approved category.

## Tool categories

| Category | Examples |
|---|---|
| Workspace reading | Read files, list files, search the repository |
| Editing | Apply a diff, create a file, delete a file |
| Execution | Run a command in the VS Code terminal and read its output |
| Browser | Open a page, click, type, scroll, capture screenshots/console logs |
| MCP | Call tools exposed by MCP servers you configure |
| Skills | Load a configured skill |
| Interaction | Ask you a question or wait for approval |

The exact tool set depends on the mode and the model. Plan mode does not edit
files; Act mode can request edits and commands.

## Approvals

Reads, edits, terminal commands, browser access, MCP tools, and unknown tools
require approval by default. Auto-approval is opt-in per category in
**Settings → General**. Approving a tool call does not approve a different
category.

## MCP tools

MCP servers are configured from the **MCP Servers** view or the MCP settings.
Once connected, their tools appear alongside built-in tools and still follow the
approval policy. Auto Phase Plan can restrict MCP servers per phase.

See [MCP overview](/mcp/mcp-overview).

## Terminal and browser

Terminal commands run in a visible VS Code terminal. Browser actions use the
configured browser; screenshots and console logs are returned to the agent. Do
not run untrusted commands or open untrusted pages with auto-approval enabled.
