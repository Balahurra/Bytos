Bytos (usage-billing) is the simplest way to get started with pay-as-you-go model access in Bytos.

Instead of managing separate API keys across multiple vendors, you sign in once, add **Bytos credits**, and select from available models directly in Bytos.

If you want a flat monthly subscription that offers 2-5x the usage on selected open coding models compared to standard API rate, use [BytosPass](/getting-started/bytospass) instead. BytosPass is a separate provider in Bytos.

## Why use Bytos (usage-billing)

- **Fastest setup**: no manual API key copy/paste; access to 100+ models supported by Bytos
- **One account**: sign in once with Google, GitHub, or email
- **Pay as you go**: add Bytos credits and use one balance across supported models
- **Free options**: look for models tagged **FREE** in the selector

## How it works

Bytos (usage-billing) is the pay-as-you-go provider in Bytos. Add Bytos credits, then select **Bytos** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **Bytos**, and sign in.
- **CLI**: Go to `/settings` and select **Bytos** as your provider.

## Credits and usage

- Add **Bytos credits** from your [Bytos dashboard](https://app.bytos.dev/dashboard)
- Credits are used on a pay-as-you-go basis when you select paid models through Bytos (usage-billing)
- View usage in Bytos Settings → **View Usage**
- Switch organizations in Bytos Settings → **Switch Organization**
