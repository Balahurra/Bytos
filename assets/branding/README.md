# Bytos brand assets

The mark is a geometric **B** built from three rounded strokes: a vertical stem
and two open bowls. The cut in each bowl reads as a byte being written, and the
cyan node is the agent's checkpoint.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Midnight | `#070B14` | App icon background, dark surfaces |
| Cyan | `#22D3EE` | Primary accent, focus, live state |
| Blue | `#4F8CFF` | Primary action, links |
| Violet | `#8B5CF6` | Gradient end, secondary accent |
| Ink | `#0B1220` | Text on light backgrounds |
| Snow | `#F8FAFC` | Text on dark backgrounds |

The signature gradient runs from cyan to blue to violet at 135 degrees.

## Rules

- Keep clear space equal to at least 25% of the mark's width on every side.
- Do not stretch, rotate, add shadows to, or recolor the mark outside the
  approved palette.
- Use the wordmark lockup when the product name is not already visible.
- Do not place the gradient mark on a busy photograph. Use the monochrome mark
  instead.
- The mark must never be smaller than 16 px. Below 24 px, use the app icon tile.
