# Archived documentation

This folder contains documentation for surfaces that are **not shipped in the
current Bytos VS Code extension release**:

- Desktop app
- CLI / TUI / ACP / cloud agents
- JetBrains plugin
- SDK and plugin marketplace
- Kanban
- Bytos Provider / BytosPass hosted billing
- Enterprise SSO / remote configuration / monitoring
- Public Bytos API
- Subagents and plugin installation flows that apply only to other surfaces

They are kept here for historical reference only. They are **not part of the
current product documentation** and are not linked from the shipped docs
navigation.

The current release is the VS Code extension with:

- bring-your-own-key (BYOK) model providers;
- approval-first tools;
- sequential Auto Phase Plan (up to 10 phases);
- MCP, hooks, skills, checkpoints, worktrees, and task history;
- local voice dictation on Windows x64.

See `/bytos-overview` and `/status-and-roadmap`.
