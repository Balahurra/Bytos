## Choose Your Install Path

- [Desktop App](#desktop-app) — Bytos as a native app
- [IDE Extension](#ide-extension) — VS Code, Cursor, JetBrains, Windsurf, VSCodium, Antigravity

- [SDK](#sdk) — build with `@bytos/sdk`

## Desktop App

Use this if you want Bytos outside your editor, as a native desktop app with a dedicated workspace for running and managing agent sessions.

<Steps>
  <Step title="Download Bytos Desktop">
    Get the installer for your platform from [bytos.dev/desktop](https://bytos.dev/desktop). Available for macOS and Windows (Windows is currently in beta).
  </Step>
  <Step title="Choose a provider and model">
    Select the provider and open weight model of your choice. Bytos Desktop is an open source app for open weight models, so you bring your own model access.
  </Step>
  <Step title="Start a session">
    Run sessions in parallel, schedule recurring tasks, and import sessions from other coding agents to continue in Bytos.
  </Step>
</Steps>

More details: [Bytos Desktop](/usage/bytos-desktop), and for remote machines [Bytos Desktop SSH](/usage/bytos-desktop-ssh)

## IDE Extension

Use this if you want Bytos inside your editor UI.

<Tabs>
  <Tab title="VS Code / Cursor / Windsurf / VSCodium / Antigravity">
    <Steps>
      <Step title="Open Extensions">
        Press `Ctrl/Cmd + Shift + X`.
      </Step>
      <Step title="Search for Bytos">
        Type `Bytos`.
      </Step>
      <Step title="Install">
        Click **Install** on the Bytos extension.
      </Step>
      <Step title="Open Bytos">
        Find Bytos in the extension sidebar.
      </Step>
      <Step title="Authorize with Bytos">
        After installing the extension, complete provider setup in Bytos settings. Use the Bytos Provider for pay-as-you-go access, BytosPass for a flat monthly subscription, or bring your own provider key.

        [Authorize with Bytos](/getting-started/authorizing-with-bytos)
      </Step>
    </Steps>

    <Note>
    Windsurf and VSCodium use Open VSX. The install flow is the same.
    </Note>
  </Tab>

  <Tab title="JetBrains">
    <Steps>
      <Step title="Open Plugins Marketplace">
        **Settings** → **Plugins** → **Marketplace**.
      </Step>
      <Step title="Install Bytos">
        Search `Bytos`, click **Install**, then restart the IDE.
      </Step>
      <Step title="Open Bytos">
        **View** → **Tool Windows** → **Bytos**.
      </Step>
      <Step title="Authorize with Bytos">
        After installing the extension, complete provider setup in Bytos settings. Use the Bytos Provider for pay-as-you-go access, BytosPass for a flat monthly subscription, or bring your own provider key.

        [Authorize with Bytos](/getting-started/authorizing-with-bytos)
      </Step>
    </Steps>

    Alternative: install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/28247-bytos).
  </Tab>
</Tabs>

## CLI

Use this if you want Bytos in terminal workflows (interactive + automation).

<Steps>
  <Step title="Install Node.js">
    Install Node.js 20+ (22 recommended).
  </Step>
  <Step title="Install CLI">
    ```bash
    npm install -g bytos
    ```
  </Step>
  <Step title="Authenticate">
    ```bash
    bytos auth
    ```
  </Step>
  <Step title="Run Bytos">
    ```bash
    bytos
    # or
    bytos "your task"
    ```
  </Step>
</Steps>

More details: [CLI Installation & Setup](/usage/cli-overview)

## Kanban

Use this if you want task-board workflows with agent execution.

<Steps>
  <Step title="Install Node.js">
    Install Node.js 18+.
  </Step>
  <Step title="Launch Kanban">
    ```bash
    npx kanban
    ```
  </Step>
</Steps>

More details: [Kanban](/usage/kanban)

## SDK

Use this if you are building your own app/agent on top of Bytos.

<Steps>
  <Step title="Create project">
    ```bash
    mkdir my-agent && cd my-agent
    npm init -y
    ```
  </Step>
  <Step title="Install SDK">
    ```bash
    npm install @bytos/sdk
    ```
  </Step>
  <Step title="Build and run">
    Browse SDK examples to run your first agent.
  </Step>
</Steps>

Start here: [SDK Examples](/sdk/examples)
