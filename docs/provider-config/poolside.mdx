Poolside provides coding-focused AI models through an OpenAI-compatible API.

**Website:** [https://poolside.ai/](https://poolside.ai/)

### Get API Credentials

1.  **Sign Up/Sign In:** Go to the [Poolside Platform](https://platform.poolside.ai/) and create an account or sign in.
2.  **Navigate to API Keys:** Open the **API Keys** tab.
3.  **Create a Key:** Click **New key** to create an API key.
4.  **Copy the Key:** Copy the API key immediately and store it securely.

### Configuration in Bytos

> See [Authorization & Model Selection](/provider-config/overview).

1.  **Open Bytos Settings:** Click the settings icon (⚙️) in the Bytos panel.
2.  **Select Provider:** Choose "Poolside" from the "API Provider" dropdown.
3.  **Enter API Key:** Paste your Poolside API key into the "Poolside API Key" field.
4.  **Select Provider Model:** Choose your desired model from the "Model" dropdown.

### Tips and Notes

-   **Model Access:** Choose from the Poolside models in the "Model" dropdown. Availability depends on your Poolside account.
-   **OpenAI-Compatible API:** Bytos connects to Poolside's OpenAI-compatible endpoint and configures the base URL automatically when you select Poolside.
-   **OpenRouter Access:** Poolside models may also be available through [OpenRouter](/provider-config/openrouter). To use them there, select OpenRouter and use an OpenRouter API key.
