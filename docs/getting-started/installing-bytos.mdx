Bytos is distributed as a **Visual Studio Code extension**. A Bytos account is
optional; chat and BYOK work without one, and model requests go directly to the
provider you configure by default. If you select the BytosPass provider, requests
go to the Bytos API as part of that subscription.

## Requirements

- **Visual Studio Code 1.101.0 or newer** (VS Code Insiders works too).
- A model provider API key, or a local model server such as Ollama or LM Studio.
- **Windows x64** for the current local voice-dictation feature. The core
  extension is tested on Windows, macOS, and Linux; voice capture is Windows x64
  only in this release.
- An internet connection for cloud providers. Local models do not need one.

## Install from the VS Code Marketplace

1. Open [Bytos on the VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Bytos.bytos).
2. Click **Install**, or run:

   ```bash
   code --install-extension Bytos.bytos
   ```

3. Open the Bytos view in the VS Code activity bar.

## Install from a VSIX

If you have a verified VSIX artifact:

```bash
code --install-extension bytos-<version>.vsix
```

Then open the Bytos view in the activity bar.

## Configure a provider

1. Open **Settings → API Configuration**.
2. Choose a provider. Supported integrations include OpenRouter, Anthropic,
   OpenAI, Google Gemini, AWS Bedrock, Azure, GCP Vertex, Cerebras, Groq, any
   OpenAI-compatible endpoint, and local models through Ollama or LM Studio.
3. Paste your API key, or configure the local endpoint.
4. Select a model.

Your key is written to VS Code SecretStorage, never to a plaintext settings file,
and the webview only receives a masked value and a configured/not-configured
status. See [Providers and models](/provider-config/overview) for per-provider
setup.

## Run your first task

1. Open a workspace folder in VS Code.
2. Open the Bytos panel.
3. Describe a task, for example:

   > Add a health-check endpoint to this Express app, add a test, and run the
   > test suite. Ask before changing files outside `src/`.

4. Review the plan and approve the file/terminal actions you want Bytos to take.
5. Review the diffs and test output. Use checkpoints if you want to restore an
   earlier state.

See [Quick start](/getting-started/quick-start) for a shorter walkthrough and
[Plan and Act](/core-workflows/plan-and-act) for the workflow model.

## Optional: voice dictation

On **Windows x64**, Bytos can record from your microphone and transcribe locally
with the bundled whisper.cpp engine:

1. Open **Settings → Voice**.
2. Turn on **Voice**.
3. Press **Refresh** in the Microphone section and choose an input device.
4. Download a speech model if none is installed.
5. Use the microphone button in the chat composer.

Audio stays in memory and is never uploaded to a Bytos service. See
[Voice and microphone troubleshooting](/troubleshooting/voice-and-microphone).
