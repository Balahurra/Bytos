## Shipped in the current VS Code extension

- Chat-first agent for VS Code with Plan / Act modes.
- Approval-first file reads, edits, terminal commands, browser access, MCP tools,
  and unknown tools.
- Bring-your-own-key providers and local models.
- File editing with diffs, terminal execution, browser automation, MCP tools.
- Hooks, skills, worktrees, checkpoints, and task history.
- Sequential **Auto Phase Plan** with up to 10 phases, per-phase provider/model/
  API key/MCP, failure handling, and Markdown reports.
- Local voice dictation on **Windows x64** (microphone discovery, device
  selection, bundled whisper.cpp engine, on-demand speech models).
- Opt-in telemetry, off by default.

## Not part of this release

- Desktop app
- CLI, TUI, ACP, and cloud agents
- JetBrains plugin
- SDK and plugin marketplace
- Kanban
- Bytos Provider / BytosPass hosted billing
- Enterprise SSO, remote configuration, and monitoring
- Public Bytos API

Historical documentation for these surfaces is kept under
[`docs/_archive/`](https://github.com/Balahurra/Bytos/tree/main/docs/_archive)
for reference. It is not part of the current product docs.

## Planned

There is no dated public roadmap in this repository yet. Planned work is tracked
in GitHub Issues and Projects when maintainers publish it. Do not treat a feature
mentioned in an archived document or an example as shipped until it is listed
under “Shipped”.
