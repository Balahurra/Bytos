BytosPass is a low-cost monthly subscription — **$9.99/month** — that offers **2-5x the usage** on popular open coding models compared to standard API rate.

It's completely optional. You don't need BytosPass to use Bytos, and you can always use any other provider alongside it.

## How it works

BytosPass is a separate provider in Bytos. After subscribing, select **BytosPass** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **BytosPass**, and sign in.

  <img src="/assets/bytospass/bytospass-ide-extension.png" alt="Bytos IDE extension settings with BytosPass selected as the API Provider" />
</Frame>

- **CLI**: Go to `/settings` and select **BytosPass** as your provider.

## Why BytosPass

Open models have gotten really good. They now reach performance close to proprietary models for coding tasks, and because many providers can serve them competitively, they're usually far cheaper.

However, getting reliable access can be difficult. Providers vary in quality and availability, and standard rate limits can throttle heavy agentic workflows that read files, run commands, and iterate across many turns.

BytosPass solves this by:

- Curating a select group of open models tested and benchmarked for coding agent use
- Offering **2-5x the usage** on popular open coding models compared to standard API rate, so you can run long, complex agent tasks without interruption
- Providing stable access through Bytos's infrastructure

<Note>
BytosPass is a separate provider from Bytos (usage-billing). You can use both independently — subscribe to BytosPass for 2-5x the usage on popular open coding models compared to standard API rate, or use Bytos (usage-billing) for pay-as-you-go access.
</Note>

## Using BytosPass outside of Bytos

You can use BytosPass models from your own scripts, apps, or automation through the Bytos API. The API uses the same OpenAI-compatible Chat Completions format as the rest of Bytos's API.

To get started, create an API key from **Settings > API Keys** in [app.bytos.dev](https://app.bytos.dev). For the complete walkthrough, see the [Bytos API Getting Started guide](/api/getting-started).

Use the full BytosPass model slug in the `model` field:

```bash
export BYTOS_API_KEY="your_api_key_here"

curl -X POST https://api.bytos.dev/api/v1/chat/completions \
  -H "Authorization: Bearer $BYTOS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "bytos-pass/qwen3.7-max",
    "messages": [
      {"role": "user", "content": "Write a TypeScript function that validates an email address."}
    ],
    "stream": false
  }'
```

## Usage

BytosPass measures usage against three limits:

- **5-hour rolling window** — your usage within rolling 5-hour period
- **Weekly** — your usage over the calendar week
- **Monthly** — your usage over the calendar month

To check your current usage, visit your [Bytos dashboard](https://app.bytos.dev/dashboard/subscription?personal=true).
