## 1. Open a workspace

Open a project folder with **File → Open Folder**. Bytos needs a workspace so it
knows where it may read and edit files.

## 2. Open the Bytos panel

Click the Bytos icon in the VS Code Activity Bar. If you cannot find it, open the
Command Palette (`Ctrl/Cmd + Shift + P`) and run **Bytos: Open In New Tab**.

## 3. Describe the task

Be specific about the outcome and the boundary:

> Add a `/api/health` endpoint with a test. Keep changes inside `src/` and
> `tests/`. Ask before running any command that installs packages.

## 4. Review the plan and approvals

Bytos proposes a plan, then asks before actions such as reading files, editing,
running terminal commands, opening a browser, or calling MCP tools. Approve only
what the task needs.

## 5. Review the diff and verification

- Read each diff before accepting it.
- Watch terminal commands in the VS Code terminal.
- Check test output and diagnostics.
- Use checkpoints to compare or restore an earlier state.

## 6. Stop or recover

Use the stop control to end a running task. If a file was changed unexpectedly,
open the checkpoint controls and restore the earlier state.
