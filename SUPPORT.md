## Bugs

Open a [Bug Report](https://github.com/Balahurra/Bytos/issues/new?template=bug_report.yml)
with:

- Bytos and VS Code versions;
- operating system;
- provider and model;
- minimal reproduction steps;
- redacted logs or screenshots.

Do not include API keys, tokens, or private code.

## Feature requests

Open a [Feature Request](https://github.com/Balahurra/Bytos/issues/new?template=feature_request.yml).
Describe the problem first, then the proposed change. Features need maintainer
approval before implementation.

## Questions

Open a [Question / Help](https://github.com/Balahurra/Bytos/issues/new?template=question.yml)
issue or ask in [Discord](https://discord.gg/2hSFZY9Bs).

## Security

Do **not** open a public issue for a vulnerability. Use the private advisory
form: <https://github.com/Balahurra/Bytos/security/advisories/new>. See
[SECURITY.md](SECURITY.md).
